These requirements evolved in two stages:
1. IPE (or IDE) - Integrated Projecting Environment
   Designed to improve tools and processes in all phases of project work at CTEK

2. PDB - Project Database
   A subset of the requirements from the IPE to give the best return on investment. Focused on core engineering phases.

The same URS was used for both. IPE-PDB_URS_MarkedUp.pdf
It was marked up with highlighter for the PDB development.
Green = Mandatory
Blue = Desirable

The PBD requirements are probably well suited for the current Process Sequence Engineering Platform.
Work was started on the PDB but never completed.
